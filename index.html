First draft notes

This app is designed to work without hosting. It stores records in the browser you use. Use Setup > Import JSON or the Device Sync JSON section to move the full app data between your phone and laptop. Previously entered names, emails, roles, task titles and locations are suggested as you type. On iPhone, the app now shows its own suggestion list instead of relying only on Safari suggestions.

Setup and travel claims

Use the Setup button to save your name, address, bank details and mileage rate. If travel is claimable for a task, choose Yes and add the miles. The app calculates the travel amount and itemises it in the payment request.

Task calendar entry

The calendar button downloads an .ics file for the task only. Payment follow-up is handled inside the dashboard, not in your calendar.

Email/payment flow

After completion, generate a payment request, then choose the general format or the Club Academy Scotland referee claim form. Use Share file, Download, Print/Save PDF, Copy email body, Email draft, or the optional .eml package.

Generate payment request

Your name, address, bank details and mileage rate are pulled from Setup. The Club Academy form uses task title as Match and job title as Type of Official. Saved custom templates from Template Manager also appear in the Request format list.

Browser email drafts cannot reliably attach generated files. For the smoothest flow: Share file first on iPhone, or Download file/Print PDF and attach manually. The .eml option is experimental and mainly useful for testing on Mac/desktop email clients.

Template Manager

v11 supports placeholder-based templates. Upload or paste an HTML/text template containing placeholders such as {{full_name}}, {Task Title} or {{total_payable}}. The app detects the placeholders, asks you to map them to app fields, then saves the reusable template locally.
For Word forms, save/export the form as HTML or paste the form text with placeholders into the box below.

Export tasks

Device sync JSON

Use this when switching between phone and laptop. Export the full sync JSON from the device with the newest data, send it to yourself by AirDrop, email, WhatsApp, iCloud Drive, Google Drive or cable transfer, then import it on the other device. The file includes tasks, setup details and bank details, so share it only through trusted routes.

Merge keeps the newest version of each task using its updated timestamp. If you deleted a task on one device and want the deletion reflected everywhere, use Replace from the device that has the correct final list.
